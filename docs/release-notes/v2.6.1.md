# MediaMop v2.6.1

Date: 2026-09-01

This release makes Refiner safer around active downloads, turns failures into recoverable operator work, and gives MediaMop a live, polished control-room interface.

## What Changed

- Dashboard is now a live operations view with animated work progress, an action queue, recent outcomes, and direct links to the next useful step.
- Refiner Files is now a timestamped action workbench with consistent rows, bulk actions, re-check and retry controls, and durable processing records.
- Libraries can enforce minimum and maximum file sizes, created/modified date windows, stable-file detection, schedules, capacity, output policy, and cleanup of rejected inputs.
- Reusable rule sets now expose ordered audio and subtitle preferences, original-language handling, metadata cleanup, and encrypted provider settings.
- Settings is reorganized into a cleaner task-based workspace, and the desktop shell has a redesigned collapsed sidebar with a compact brand mark and icon-only sign-out control.
- Refiner Files now offers **Pass through unchanged** for intentional edge cases,
  such as a film whose only audio language falls outside the saved track rules. It
  bypasses audio, subtitle, and metadata rules, but still waits for active downloads,
  validates the unchanged output, and removes the watched source only after the
  library's normal post-success safety gates pass. Large unchanged copies report live
  progress on the dashboard instead of appearing stuck.

## Fixes And Stability

- Refiner waits for downloads to become stable before processing, validates the completed output before replacing anything, and never treats a partial output as success.
- Successful processing now cleans up the source immediately; interrupted cleanup is retried safely and remains visible to the operator.
- Refiner no longer holds a database transaction open while ffprobe or ffmpeg runs, and transient SQLite collisions retry instead of becoming false failures.
- Manual processing and targeted re-checks retain the selected library, while missing files, unsupported types, held jobs, and worker failures explain the corrective action in plain language.
- Dashboard and Jobs distinguish media work from maintenance jobs and clearly identify jobs held by a global pause.
- Dashboard health, incident totals, and action links now include unresolved file-level failures from the Refiner workbench; clearing finished job history is only offered when it can actually help.
- Cancelled historical jobs are shown as terminal history instead of being mislabeled as work that still needs review.

## Upgrade Notes

- Windows users can install the release with `MediaMop-win-Setup.exe`; existing application data is preserved.
- After that one-time bootstrap, future upgrades can be started from **Settings -> Upgrade**.
- Existing databases, settings, and processing records are preserved; the new actions are additive.
