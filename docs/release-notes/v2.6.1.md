# MediaMop v2.6.1

Date: 2026-09-01

This release turns Refiner failures into recoverable operator work and gives the app a clearer, more polished control-room interface.

## What Changed

- Dashboard attention items now explain the problem in plain language and link to the screen where it can be fixed.
- Refiner Files is now an action workbench: select several files, retry failures, re-check held files, start ready files, and open durable processing records.
- Refiner jobs show the next operator step, keep technical diagnostics secondary, and provide a safe recovery action when media work finished but result saving was interrupted.
- The desktop shell has a refreshed visual system with stronger hierarchy, clearer active navigation, and a redesigned collapsed sidebar with a compact brand mark and icon-only sign-out control.

## Fixes And Stability

- Refiner no longer holds a database transaction open while ffprobe or ffmpeg runs, preventing long media work from blocking progress and activity writes.
- SQLite waits longer for a short competing write, and Refiner metadata writes retry transient lock collisions without turning completed media work into false failures.
- Manual processing and targeted re-checks keep the selected Refiner library attached to the file, avoiding scope-only misrouting.
- Missing files, unsupported file types, and worker failures now explain the corrective action instead of surfacing only raw database or process errors.

## Upgrade Notes

- If you are upgrading from an older Windows install that predates the updater service, run `MediaMopSetup.exe` once as administrator.
- After that one-time bootstrap, future upgrades can be started from **Settings -> Upgrade**.
- Existing databases, settings, and processing records are preserved; the new actions are additive.
