# Weir v2.6.5

Date: 2026-09-07

This patch release gives Weir's multi-section areas one consistent, responsive workspace experience.

## What Changed

- Processing and Pruner now share the same page header, section tabs, context band, and content alignment.
- Settings uses the same workspace system with a grouped navigation rail suited to its larger set of sections.
- Module tabs scroll cleanly on narrow screens and wrap naturally on wider displays.

## Fixes And Stability

- Settings navigation and the active content panel keep matching top and bottom edges across every Settings section.
- Tab and panel relationships now use consistent accessibility labels and identifiers throughout the workspaces.
- Automated browser checks cover the shared desktop layout and 390-pixel mobile views without horizontal page overflow.

## Upgrade Notes

- Windows users can install this release with `Weir-win-Setup.exe`; existing users, settings, libraries, and processing history are preserved.
- No configuration or database migration is required for this release.
- Existing v2.6.4 installations can use **Check for updates** from the tray or install the new setup file directly.
