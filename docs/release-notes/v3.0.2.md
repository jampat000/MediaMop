# Weir v3.0.2

Date: 2026-09-19

This release makes Weir work properly with Sonarr and Radarr, and sets each library up for the media manager it works with.

## What Changed

- **Sonarr and Radarr, set up for you.** Edit a library and its new **Media manager** section shows exactly what to enter in Sonarr or Radarr's **Remote Path Mappings**, with copy buttons. Press **Check again** and Weir reads Sonarr/Radarr's settings (it never changes them) and shows ✓, or tells you in plain words what to fix. Step-by-step guide: [Connecting Deluno, Sonarr and Radarr](https://jampat000.github.io/Weir/docs/guides/media-managers).
- **Deluno libraries fill themselves in.** A library that works with Deluno explains there's nothing to map, and offers to fill in its folders from what Deluno reports.
- **New library switch: "After cleaning, remove the original download."** It's on by default, so nothing changes unless you turn it off. Turn it off if you use torrents, so they keep seeding. Weir remembers what it has already cleaned, so it won't clean a kept original again.
- **A new README and documentation site**, written for people installing Weir: Docker Compose examples, Windows install, first steps and troubleshooting.

## Fixes And Stability

- **No more half-written files in the output folder.** When Weir's work folder and output folder were on different drives, which is common in Docker, the cleaned file was copied into place under its final name, and Sonarr or Radarr could import it before the copy had finished. Weir now copies to a hidden file first and only gives it its real name once it's complete.
- **Deluno libraries found through "Import from a media manager"** now watch Deluno's downloads folder, where hand-offs come from, instead of its finished library folder.
- Sonarr and Radarr's description in **Settings → Media managers** now says what the connection actually does.

## Upgrade Notes

- Weir updates its database automatically when it starts (one new library setting). Databases from 3.0.2 can't be opened by 3.0.1 or earlier, so take a backup first if you want a way back.
- Using Sonarr or Radarr with a torrent client? After upgrading, turn **After cleaning, remove the original download** off on those libraries, then follow the guide above.
- Windows: **Settings → Upgrade** or **Check for updates** in the tray, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
