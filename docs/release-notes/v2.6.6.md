# Weir v2.6.6

Date: 2026-09-07

This patch release restores a clearer horizontal navigation pattern across Weir and makes busy screens smoother and easier to scan.

## What Changed

- Settings, Processing, and Pruner now share one themed horizontal section bar, with safe horizontal scrolling on narrow screens.
- Processing audio and subtitle profiles use a clearer step-by-step layout with readable language names and advanced ordering kept out of the way until needed.
- The Dashboard focuses on live work and items that need attention; completed history remains available in Activity and module job views.

## Fixes And Stability

- Signed-in pages use normal document scrolling instead of a nested fixed-height content pane, improving wheel and trackpad behavior.
- Dashboard live-event refreshes are narrowed and throttled to reduce unnecessary requests and rendering work.
- Settings display-density choices keep their labels and descriptions aligned at every density.
- Browser test processes now shut down their exact Vite child process so preview runtimes are not left behind after testing.
- Automated browser checks cover the shared desktop and mobile section bars, Processing profile editor, Dashboard, and document scroll ownership.

## Upgrade Notes

- Windows users can install this release with `Weir-win-Setup.exe`; existing users, settings, libraries, and processing history are preserved.
- No configuration or database migration is required for this release.
- Existing installations can use **Check for updates** from the tray or install the new setup file directly.
