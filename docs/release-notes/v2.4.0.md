# MediaMop v2.4.0

Date: 2026-08-26

This release lets MediaMop work with any media manager, not just Radarr and Sonarr, and adds the ability to clean a file *before* the manager imports it.

## What Changed

- **Settings -> Media managers** is new. Add the apps that send work to MediaMop, give each one an address and API key, test the connection, and turn it on or off.
- MediaMop now supports **Deluno** alongside Radarr and Sonarr, plus a plain payload shape anything else can post. Adding a new one no longer needs a MediaMop update.
- New behaviour: a manager can **hand a file over before importing it**. MediaMop cleans it, then tells the manager the cleaned file is ready and where to find it. Previously MediaMop could only react to files that had already been imported.
- Each media manager now gets **its own webhook secret**, generated in Settings and shown once. Replacing one manager's secret no longer stops the others from working.
- Every manager now posts to a single address, `/api/v1/intake/webhook/<name>`, shown on its card in Settings.

## Fixes And Stability

- A file handed over for cleaning is now matched to a manager's own job reference, so a repeat message after a restart returns the job already in progress instead of processing the same file twice.
- If a manager points MediaMop at a folder Refiner is not watching, the error now names both settings that disagree instead of failing later with an unclear file error.
- A file that needed no changes, or that was skipped by a safety guardrail, is now reported back accurately — a skipped file is no longer reported as ready to import.
- A manager that is switched off or unreachable can no longer cause a cleaning pass that already succeeded on disk to be marked as failed.

## Upgrade Notes

- If you are upgrading from an older Windows install that predates the updater service, run `MediaMopSetup.exe` once as administrator.
- After that one-time bootstrap, future upgrades can be started from **Settings -> Upgrade**.
- **Any Sonarr or Radarr connection you had saved is carried across automatically**, along with its automatic search settings, and will appear under Settings -> Media managers.
- **The old connection addresses have been removed.** If you had scripted against `/api/v1/arr-library/arr-connection/...`, `/api/v1/subber/webhook/radarr` or `/api/v1/subber/webhook/sonarr`, point those at `/api/v1/intake/webhook/radarr` and `/api/v1/intake/webhook/sonarr` instead. Radarr and Sonarr themselves send the same payload as before, so only the address changes.
- Subber's own Sonarr and Radarr settings are unchanged in this release.
