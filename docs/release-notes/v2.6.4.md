# Weir v2.6.4

Date: 2026-09-06

This maintenance release makes Settings layouts consistent and restores easy access to update checks from the Windows tray.

## What Changed

- The Settings workspace navigation now aligns with the full content area on every Settings tab.
- The Windows tray menu always shows **Check for updates**.
- Manually staged or otherwise unmanaged Windows copies now open **Settings -> Upgrade** when the tray update action is selected.

## Fixes And Stability

- Settings navigation and content now share the same top and bottom edges on desktop layouts.
- Compact and responsive Settings layouts retain the corrected alignment without breaking sticky navigation.
- Automated browser geometry checks and Windows tray tests guard both fixes against regressions.

## Upgrade Notes

- Windows users should install `Weir-win-Setup.exe`; existing users, settings, libraries, and processing history are preserved.
- No configuration or database migration is required for this release.
- A manually copied Weir installation should run this installer once to restore normal Velopack-managed upgrades.
