# Weir v2.6.3

Date: 2026-09-06

This maintenance release protects Processing sidecars from interrupted copies and makes Windows release builds reproducible.

## What Changed

- Processing now stages subtitle, metadata, and artwork sidecars before publishing them beside processed media.
- Windows builds now use the same Velopack CLI version as the tray application instead of reusing an incompatible global version.
- Windows installation and upgrade guidance now describes the current per-user tray application and installer.

## Fixes And Stability

- An interrupted sidecar copy can no longer leave a partial file that a later run mistakes for a completed migration before source cleanup.
- The Windows packaging fast path now preserves and reuses its existing tray output as intended.
- CI and release builds pin Velopack consistently, with automated checks guarding against future version drift.

## Upgrade Notes

- Windows users should install `Weir-win-Setup.exe`; existing users, settings, libraries, and processing history are preserved.
- No configuration or database migration is required for this release.
- Users upgrading from v2.2.x or earlier should uninstall the legacy application before running the current installer; runtime data under `C:\ProgramData\Weir` is preserved.
