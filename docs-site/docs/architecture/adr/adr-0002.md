# ADR-0002: Database and Alembic (SQLite-first)

**Status:** Accepted

Weir uses file-backed SQLite as its primary database with Alembic for schema migrations. No external database service is required.

**Later change:** [ADR-0017](https://github.com/jampat000/Weir/blob/main/docs/adr/ADR-0017-backend-on-dotnet.md) moved the backend to C# / .NET 10 in `apps/server` (the Python `apps/backend` was removed in #523). SQLite stays, but schema changes are now numbered SQL migrations in the .NET server; Alembic is no longer used. The server still records its revision in the `alembic_version` table so existing databases open unchanged.
